# Web-Block1-Portfolio

Static team portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

## Local Hosting with Caddy

This project uses [Caddy](https://caddyserver.com/) as its local web server.

### 1. Install Caddy
- *Windows:* winget install CaddyServer.Caddy
- *macOS:* brew install caddy
- *Linux:* sudo apt install caddy

### 2. Run Server
Open a terminal in the project directory and run:
caddy run

### 3. Access Website
Open your browser at:
- *URL:* [http://localhost:8080](http://localhost:8080)
