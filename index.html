QUYẾT ĐỊNH HIỆN TẠI

Vì sao chọn HTML, CSS, JS thuần?

HTML, CSS và Vanilla JavaScript là lựa chọn phù hợp cho website portfolio nhóm này.

Nhẹ và nhanh

  • Portfolio nhóm có quy mô nhỏ nên công nghệ thuần là đủ, nhẹ và dễ host.

Không cần cài đặt hay build

  • Mở file bằng trình duyệt là chạy, không cần môi trường phát triển phức tạp.

Phù hợp với đề bài

  • HTML + CSS + JavaScript đáp ứng đầy đủ yêu cầu giao diện, nội dung và tương tác cơ bản.

Hạn chế cần lưu ý

  • Khi dự án lớn hơn, JavaScript thuần sẽ khó quản lý state và luồng xử lý.
  • Component không có cơ chế tái sử dụng rõ ràng như React hoặc Vue.
  • Việc bảo trì và phối hợp code có thể mất thời gian hơn khi giao diện có nhiều phần lặp lại.

ĐÃ CÂN NHẮC

Vì sao không dùng React?

React phù hợp với ứng dụng lớn, nhiều state và component. Với website portfolio nhỏ, framework này chưa thực sự cần thiết.

Quyết định: dùng JavaScript thuần để không phải setup project hay build tool.

T

ĐÃ CÂN NHẮC

Tailwind CSS

  • Có rất nhiều class, khiến HTML dài và rối vì một thẻ có thể mang cả chục class.
  • Khó nhìn code vì style nằm lẫn trong HTML.
  • Phức tạp hơn mức cần thiết, không phù hợp với portfolio nhỏ này.

Quyết định: CSS thuần đủ đáp ứng yêu cầu và dễ chỉnh sửa hơn cho cả nhóm.

B

ĐÃ CÂN NHẮC

Bootstrap

  • File CSS/JS khá nặng so với nhu cầu của một portfolio nhỏ.
  • Khó ghi đè CSS nếu muốn tùy chỉnh giao diện theo phong cách riêng.
  • Phức tạp hơn vì phụ thuộc vào thư viện bên ngoài.

Quyết định: CSS thuần giúp giao diện nhẹ, linh hoạt và không cần dependency.
